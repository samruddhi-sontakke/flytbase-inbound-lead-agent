[9:00 – 9:45] The design decision I'm proudest of is the split between the AI and the code. The AI reads, judges and writes. Python decides anything that has to be exact: the scores, which facts survive, whether a partner name is real, and whether each stage meets the PDF. That's also why the orchestration is dependency-aware and every stage saves through the same validated path. It matters because it fails safe. On the first SQM run, the fact-checker was only shown the first part of each source, so it removed 16 claims that were actually true. Nothing false got through, but real research was lost. I found it, fixed the tool so it passes the relevant passages and the full text, re-ran the check, and none were removed. On the E.ON lead, a Word file was stored as unreadable data, and the checker cut every claim that rested on it rather than trusting it. Nothing unsourced reaches the AE.
