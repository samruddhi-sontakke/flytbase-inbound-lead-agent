Inbound Lead Desk · 3 / 15

[1:10 – 2:10] Here's the architecture. Claude Code is the AI agent. It's connected to Gmail through an email MCP, which can read and label mail. Sending, replying and drafting are blocked in its settings. A cron runs every five minutes, so the agent checks the inbox on its own rather than me triggering it. Claude Code is the orchestrator: it decides what to run and hands each stage to its own subagent. There are seven, one per PDF stage plus an independent fact-checker, and each one is a versioned file with its own instructions and output format, so the logic is inspectable. Everything that has to be exact lives in a Python MCP server I wrote, called leaddesk: the scoring, the source registry, the website crawls, removing unsupported claims, checking partner names and checking every stage against the PDF. Results go into MongoDB, and the Lead Desk web app shows them. So this isn't one prompt producing a report. It's a multi-stage workflow with separate responsibilities, stored outputs and validation.
